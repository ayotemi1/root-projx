---
name: Supporter profile sharing
description: Opt-in profile interests, visitor-equivalent Preview, and non-financial involvement entries.
---

Only interests explicitly chosen for profile display are public. Saving private
onboarding interests is not consent to publish them. Profile Preview must use
the same public projection as a stranger, without owner-only controls, Saved or
private involvement; a hidden profile has a hidden visitor view.

**Why:** The user requested a faithful visitor preview and disclosure only of
interests and activities the supporter chooses to share.

**How to apply:** Keep ownership separate from visitor visibility. Do not infer
public consent from an organisation follow, community tag or private preference.

Manual involvement is a participation record, not a financial transaction. A
manual Gave entry must never create or modify donations, receipts, raised totals
or giving history. Approximate dates and activities before joining are valid;
outside projects are valid and labelled “Not on Root ProjX yet”.

**Why:** The user explicitly wants historical and off-platform participation,
while keeping donation amounts out of Involvement and private giving private.

**How to apply:** Derive automatic activity only from explicit recorded links
and real activity types, not caption guesses. A public supporter-wall opt-in is
not an explicit request to publish a donation post.
