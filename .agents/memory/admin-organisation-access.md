---
name: Admin organisation access
description: Scope and security boundary for administrators managing organisation dashboards.
---

Administrators need to set up profiles and campaigns on behalf of any organisation without obtaining or replacing its password. Reuse the actual owner editors and previews rather than maintaining a separate, incomplete admin editor.

**Why:** The user explicitly requested access to every organisation's page to manage their setup. This is content management, not a request to impersonate an organisation's bank account holder or change its login.

**How to apply:** Keep administrator mode visibly labelled and separate from the normal user session. Restrict delegated access to the selected organisation and existing content tools; banking setup and settlement remain in their dedicated admin flows. Never bypass campaign publication requirements while managing an organisation.
