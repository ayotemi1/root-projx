Architecture — build exactly this:
Monorepo with four packages:

mobile — Expo React Native, iOS and Android
web — React, fully responsive, desktop and mobile browser
api-server — Express, TypeScript
db — Drizzle ORM, PostgreSQL via Replit database


Database — PostgreSQL + Drizzle:
Use the schema files from the reference as the exact table structure. Tables needed:

users — id, name, email, phone, password_hash, account_type (supporter/organisation), avatar_initials, created_at, token
organisations — id, user_id, org_name, mission, location, country, cause_category, goal_amount, raised_amount, distributed_amount, donor_count, follower_count, verified, help_opted_in, help_services, response_commitment, whatsapp_number
donations — id, supporter_id, org_id, amount, currency, type (one-time/recurring), processor (stripe/paypal), platform_fee, status, created_at
follows — id, supporter_id, org_id, created_at
updates — id, org_id, title, body, tag (Before/During/After), media_urls, sent_to_count, created_at
help_reviews — id, org_id, reviewer_session, reviewer_name, rating, body, verified_recipient, flagged, created_at
contact_events — id, session_id, org_id, need_category, channel (whatsapp/email), review_left, created_at
resources — id, org_id, title, body, category, created_at

Seed the database with realistic dummy data on first run — at least 6 organisations (mix of Jamaica and UK), 10 feed updates, 4 help reviews, 3 resources. Use the dummy data from data.ts in the reference as the seed content.

API Server — Express + TypeScript:
All routes properly connected to the database. No hardcoded data anywhere.
Auth routes:

POST /auth/register — name, email, phone, password, account_type. Hash password with bcrypt. Return JWT.
POST /auth/login — email, password. Verify bcrypt hash. Return JWT.
POST /auth/logout — invalidate token
GET /auth/me — return current user from JWT

Organisation routes:

GET /organisations — list all, supports ?country= and ?search= filters
GET /organisations/:id — single org with full profile
POST /organisations — create org profile (requires auth, account_type = organisation)
PATCH /organisations/:id — update org profile

Donation routes:

POST /donations — create donation, trigger Stripe, auto-follow org on success
GET /donations/my — current user's donation history

Feed routes:

GET /feed — all updates from orgs the current user follows
GET /feed/org/:id — all updates for a specific org
POST /feed — org posts a new update, triggers Brevo newsletter

Follow routes:

POST /follows — follow an org
DELETE /follows/:orgId — unfollow
GET /follows/my — list of orgs current user follows

Help routes:

GET /help/orgs?need= — orgs opted into Get Help, filtered by need category
POST /help/contact — log a contact event
GET /help/reviews/:orgId — all reviews for an org
POST /help/reviews — submit a review

Profile routes:

GET /profile — current user full profile
PATCH /profile — update name, email, phone
