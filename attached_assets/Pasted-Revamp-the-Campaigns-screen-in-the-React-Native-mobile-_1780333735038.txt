ACTIVE CAMPAIGNS LIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Section heading "Active Campaigns" in bold
- Vertical scrollable list of campaign cards, 
  each containing:

  TOP SECTION:
  - Campaign thumbnail image (full width, 
    rounded top corners)
  
  BOTTOM SECTION (white card body):
  - Campaign name in bold
  - Short description (2 lines, grey text)
  - Progress bar:
    - Red fill showing % complete
    - Percentage label on the right (e.g. "65%")
  - Two values below bar:
    - Left: amount raised in bold red 
      (e.g. "£6,500 raised")
    - Right: goal in grey (e.g. "£10,000 goal")
  - For volunteer campaigns:
    - Show volunteer count needed instead 
      (e.g. "42 volunteers needed")
    - Status tag (e.g. "Ongoing")
  - Action button full width at bottom:
    - "Donate" in red for fundraising campaigns
    - "Get Involved" in red for volunteer campaigns

- "See All Campaigns" full width red button 
  at the bottom of the list
