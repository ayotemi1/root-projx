Revamp the Volunteer page for organisation profiles to match

PAGE HEADER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Page heading: "Ways to Volunteer"
- Subheading: "Your time and skills can make a real difference 
  in the lives of young people."
- Filter chips in a row below the heading:
  All | Local | Remote | Short Term | Long Term
  - Active chip: red filled, white text
  - Inactive chip: outline, grey text

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
VOLUNTEER ROLES LIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- Vertical list of volunteer role cards, each containing:

  LEFT SIDE:
  - Coloured circular icon (each role has a different 
    accent colour — use brand red, gold, green, blue, 
    purple to vary them)
  - Role icon inside the circle (person, heart, calendar, 
    chat bubble etc — use relevant Lucide icons)

  MIDDLE:
  - Role title in bold (e.g. "Graphic Designer")
  - Two tags below: location type (e.g. "Remote") and 
    frequency (e.g. "Flexible hours")

  RIGHT SIDE:
  - "Apply" button in red outline style

- Below the list: 
  - "Have a skill not listed?" text in grey
  - "Suggest Your Skills" red outline button centred below

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
SUGGEST YOUR SKILLS MODAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- When "Suggest Your Skills" is clicked, open a modal with:
  - Heading: "Suggest a Skill"
  - Text input: "What skill can you offer?"
  - Dropdown: Availability (Flexible / Weekly / Occasional)
  - Dropdown: Location preference (Remote / Local / Either)
  - Submit button in red: "Send Suggestion"
  - Submission saves to Firestore: 
    organisations/{orgId}/skillSuggestions

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
APPLY FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- When "Apply" is clicked on a role:
  - If user is not logged in: prompt to sign up or log in
  - If user is logged in: open a simple application modal:
    - Role name at the top
    - Text area: "Why do you want to volunteer for this role?"
    - Text area: "Relevant experience or skills"
    - Submit button in red: "Submit Application"
    - Submission saves to Firestore:
      organisations/{orgId}/volunteerApplications
