Revamp the Organisation Profile page (viewer side) to match 
the following design spec exactly. Do not touch any other pages.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LAYOUT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
The page has two columns:
- Left column: org identity, stats, and tabbed content
- Right column: active campaigns, ways to volunteer

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
LEFT COLUMN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
HERO IMAGE
- Full width banner image at the top of the left column
- Org avatar overlapping the bottom of the banner (circular, 
  initials fallback e.g. "CY")
- Org name next to avatar in bold, large font
- Gold verified badge if verified
- Location below name (pin icon + city, country)
- Category tag below location (e.g. "Youth Empowerment")
- Short bio/description below that (2-3 lines)

ACTION BUTTONS
- "Follow" button (heart icon, outline style)
- "Donate" button (heart icon, red filled)
- Both sit side by side below the bio

STATS ROW
- Four stats in a row: Followers | Projects | Volunteers | Raised
- Each stat has an icon above the number and a label below
- Clean, minimal, evenly spaced

TABS
- Four tabs below the stats: Updates | Campaigns | Volunteer | About
- Default active tab is Updates
- Updates tab shows a 2-column grid of update cards
- Each update card has: timestamp, location tag, headline, 
  body text (2 lines), image grid (2x2 or single), 
  like count, comment count, share button, "View Details" 
  button in red

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
RIGHT COLUMN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ACTIVE CAMPAIGNS CARD
- Section heading "Active Campaigns" with "View all" link in red
- List of campaign cards, each showing:
  - Campaign thumbnail image
  - Campaign name (bold)
  - Short description (1 line)
  - Progress bar (red fill, shows % raised)
  - Amount raised and goal (e.g. "£6,500 raised / £10,000 goal")
  - Status tag (e.g. "Ongoing") or volunteer count if applicable
- "See All Campaigns" red button at the bottom

WAYS TO VOLUNTEER CARD
- Section heading "Ways to Volunteer" with "View all" link in red
- List of volunteer roles, each showing:
  - Role icon (coloured circle with icon)
  - Role title (bold)
  - Location type (e.g. "Remote") and frequency 
    (e.g. "Flexible hours")
  - Right arrow chevron
- "Apply to Volunteer" red button at the bottom

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
